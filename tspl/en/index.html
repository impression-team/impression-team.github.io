// Sound familiar?

The Mac sends the job,
the printer stays silent

The job shows up in the print queue and disappears, but no label comes out.
The printer worked before a macOS update and doesn't now. Reinstalling the driver doesn't help.
The driver from the vendor's website won't install or won't work on an Apple M1–M4 Mac.
The print log (/var/log/cups/error_log) shows com.apple.badarch-error.

The cause is almost always the same: the driver's filter was built only for older Intel Macs, and current macOS on Apple silicon refuses to run it. The printer is fine — the commands just never reach it. TSPL Label Print turns your label into TSPL commands itself and sends them straight to the printer, bypassing the broken driver.

// How it works

Three steps to a printed label

01

Printer in Printers & Scanners

If the printer is already added in macOS, there's nothing to do. If not, add it with any driver, for example "Generic PostScript Printer".

02

Open your label

Drag in a PDF from your marketplace or shipping account, or a PNG or JPG. The preview shows exactly what will come out.

03

Print

Set the label size and click Print. A multi-page PDF prints one page per label.

  • Auto-rotation to the label orientation, or rotate manually
  • Dithering for logos and photos, invert

  • Test label to check size and direction
  • Works offline and sends nothing anywhere
  • English and Russian interface; tested on Xprinter XP-360B with Apple silicon Macs

// FAQ

Questions

Which printers are supported?

Thermal label printers that use the TSPL / TSPL2 command language at 203 dpi, connected to your Mac over USB or the network and added in Printers & Scanners. That covers most budget Xprinter, TSC, Gprinter printers and their clones. Tested on Xprinter XP-360B. The easiest check is to download the trial and print a test label — it's free.

My printer doesn't print — will this help?

If the printer receives the job but prints nothing, and the CUPS log shows badarch, then yes, that's exactly the case this app solves. If macOS doesn't see the printer at all (it isn't detected over USB), the problem is the connection, and the app can't fix it. The trial shows this before you pay.

Do I need to remove the old driver?

No. The app sends raw jobs that bypass the driver's filter, so the old driver doesn't get in the way. You can keep the print queue as it is.

How do I go from the trial to the full version?

Buy TSPL Label Print on the Mac App Store, delete the trial copy from Applications and install the App Store version. Label sizes and other settings carry over.

Can I get a refund?

Purchases made on the Mac App Store are refunded by Apple: request one at reportaproblem.apple.com. That's why we recommend printing a few labels with the trial first.
