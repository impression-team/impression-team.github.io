# TSPL Label Print — продажа с сайта

Как устроено:

```
tspl/index.html ──(email, согласие с офертой)──▶ функция tspl-shop ──▶ ЮKassa: создать платёж
        ▲                                                                   │
        │                                          покупатель платит картой/СБП
        │                                                                   ▼
tspl/thanks.html ◀──ключ на экране── функция ◀──(проверка статуса)── ЮKassa
                                     функция ◀──HTTP-уведомление──── ЮKassa
                                        └──▶ письмо с ключом покупателю + уведомление о продаже вам
```

* Ключ подписывается закрытым ключом из `~/src/TSPLLabelPrint/Licensing/private_key.txt`. Этот файл хранится только у вас, а в облако попадает только в секрет Lockbox. В репозитории его нет.
* Один и тот же платёж всегда даёт один и тот же ключ, поэтому база данных не нужна, а повторы уведомлений не создают лишних лицензий.
* Уведомлению ЮKassa функция не верит на слово: перед выдачей ключа она заново запрашивает платёж через API.
* Тесты (без сети): `python3 tspl-shop/test_index.py`.

## 1. Подключить ЮKassa

1. Зарегистрируйтесь на yookassa.ru как ИП и подайте заявку на подключение магазина. Укажите сайт `https://impression-team.github.io/tspl/`. На странице уже есть всё, что проверяет ЮKassa: описание товара, цена, оферта (`tspl/oferta.html`), контакты и реквизиты.
2. Пока заявка на проверке, в личном кабинете можно создать **тестовый магазин**. У него свои shopId и секретный ключ, начинающийся с `test_`. С ним всё работает по-настоящему, но деньги не списываются (тестовые карты есть в документации ЮKassa).
3. **Чеки 54-ФЗ.** Подключите «Чеки от ЮKassa» или свою онлайн-кассу в разделе настроек магазина, затем деплойте с `RECEIPTS=1`. По умолчанию в чеке «Без НДС» (`vat_code=1`) и признак предмета расчёта `service`. Сверьте это с бухгалтером. Поменять можно переменными `RECEIPT_VAT_CODE` и `RECEIPT_SUBJECT` в функции.

## 2. Развернуть функцию

Нужны `yc` (Yandex Cloud CLI, `yc init`), `python3` и `zip`.

```bash
cd ~/impression-team.github.io
./tspl-shop/deploy.sh            # спросит shopId, секретный ключ ЮKassa и (если ещё нет) пароль приложения Яндекс Почты
```

Скрипт:
* создаст сервисный аккаунт и секреты в Lockbox;
* загрузит функцию;
* напишет её адрес в `tspl/index.html` и `tspl/thanks.html`.

Последний шаг — в кабинете ЮKassa открыть **Интеграция → HTTP-уведомления**, вставить этот адрес и отметить событие `payment.succeeded`.

Цена задаётся при деплое: `PRICE_RUB=499` по умолчанию. Если меняете цену, поменяйте и `var PRICE` в `tspl/index.html`.

Переход с тестового магазина на боевой:

```bash
YOOKASSA_RESET=1 YOOKASSA_SHOP_ID=<боевой shopId> RECEIPTS=1 ./tspl-shop/deploy.sh
```

И укажите тот же адрес функции в HTTP-уведомлениях боевого магазина.

## 3. Собрать и нотаризовать приложение для скачивания

В Xcode, проект `~/src/TSPLLabelPrint`:

1. Схема **TSPLLabelPrint Direct** → **Product → Archive**.
2. В открывшемся Organizer: **Distribute App → Direct Distribution → Distribute**. Сертификат Developer ID Xcode создаст сам, если его ещё нет. Apple проверит сборку, это несколько минут.
3. Когда статус станет «Ready to distribute», нажмите **Export** и сохраните `TSPL Label Print.app`.
4. Упакуйте приложение в zip, сохраняя подпись:
   ```bash
   ditto -c -k --keepParent "TSPL Label Print.app" ~/impression-team.github.io/tspl/TSPL-Label-Print.zip
   ```
5. Закоммитьте `tspl/TSPL-Label-Print.zip` и запушьте.

Сборка из схемы **TSPLLabelPrint** (без Direct) — это версия для Mac App Store, в ней нет ни пробного режима, ни ключей.

## 4. Если покупатель потерял ключ

* Откройте `https://impression-team.github.io/tspl/thanks.html?p=<номер платежа>`. Номер платежа есть в письме «Продажа TSPL Label Print» и в кабинете ЮKassa. Страница покажет тот же ключ.
* Или выпустите ключ вручную: `cd ~/src/TSPLLabelPrint/Licensing && python3 keygen.py issue "email покупателя"`. Так же выдаются ключи при оплате по счёту.

## 5. Важно

* **Сделайте резервную копию `private_key.txt`**, например в менеджер паролей. Если его потерять, новые ключи не будут подходить к уже выпущенному приложению.
* Не коммитьте `private_key.txt` ни в один репозиторий.
* Деньги за возвраты (14 дней по оферте) возвращаются из кабинета ЮKassa: Платежи → платёж → Вернуть.
